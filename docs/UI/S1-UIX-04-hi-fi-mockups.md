# S1-UIX-04: High-Fidelity Mockups

## Task

**Task ID:** S1-UIX-04

**Task:** High-Fidelity Mockups (Login, Register, Main Page, User Management, Rights Dialog).

## Design Overview

Created the high-fidelity UI mockups for the HOPE, Inc. ERP System based on the established design system.

The designs illustrate the visual appearance, layout, typography, colors, components, and user interactions across the authentication pages and main ERP application.

## Design Deliverables

### 1. Login Page
- Email input field.
- Password input field.
- Remember Me option.
- Forgot Password link.
- Sign In button.
- Sign in with Google option.

### 2. Registration Page
- Full Name input field.
- Email input field.
- Password input field.
- Confirm Password input field.
- Create Account button.
- Login link.

### 3. Main Page / Landing Page
- Introduction to the HOPE, Inc. ERP System.
- Register Now button.
- Sign In button.
- Navigation to authentication pages.

### 4. Admin User Management
- User Management list.
- User information and role display.
- User status indicators.
- Available user actions.
- Rights management access.

### 5. Superadmin User Management
- User Management list.
- User information and role display.
- User status indicators.
- User management actions.
- Rights management access.

### 6. Admin Rights Dialog
- Permission assignment dialog.
- Module permission controls.
- View, Add, Edit, and Delete permissions.
- Save Rights button.
- Cancel button.

### 7. Superadmin Rights Dialog
- Permission assignment dialog.
- Module permission controls.
- Available permission settings.
- Save Rights button.
- Cancel button.

### 8. Developer Handoff Notes
- Design tokens and typography references.
- Layout and spacing guidelines.
- Authentication screen specifications.
- Main page and user management behavior.
- Rights dialog interactions.
- Component and asset references.

## Design System Consistency

Maintained consistency with the established HOPE, Inc. ERP Design System:

- Colors and design tokens.
- Typography and font hierarchy.
- Spacing and layout.
- Navigation and sidebar components.
- Buttons, tables, and dialog components.
- Role-specific visual indicators.
