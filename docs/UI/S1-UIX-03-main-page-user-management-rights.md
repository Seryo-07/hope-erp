# S1-UIX-03: Main Page, User Management List and Rights Dialog Wireframes

## Task

**Task ID:** S1-UIX-03

**Task:** Wireframes: Main Page, User Management List and Rights Dialog.

## Design Overview

Created the main page and user management wireframes for the HOPE, Inc. ERP System.

The designs demonstrate how the application interface and available functions differ according to the user's role and assigned permissions.

## Design Deliverables

### 1. Admin Dashboard
- Dashboard layout and statistics.
- Business module navigation.
- User Management access.
- Quick Actions for available business operations.
- Restricted access to Superadmin-only functions.

### 2. Superadmin Dashboard
- Full system dashboard layout.
- Complete business module navigation.
- User Management access.
- System Settings access.
- Quick Actions for system administration and business operations.
- Full role and permission management capabilities.

### 3. User Dashboard
- Dashboard layout and statistics.
- Permission-based module navigation.
- Quick Actions based on assigned user rights.
- Restricted access to unauthorized modules and operations.

### 4. User Management List – Admin View
- User account listing.
- Name, Email, Role, Status and Actions columns.
- Add User button.
- Block and Unblock actions.
- Edit user information.
- Rights button for permission assignment.
- Restrictions on viewing and modifying Superadmin accounts.

### 5. User Management List – Superadmin View
- User account listing.
- User roles and account statuses.
- User account administration.
- Role assignment and permission management.
- Access to system-wide user administration.

### 6. Rights Dialog – Admin Permission Assignment
- Selected user information.
- Customer Management permissions.
- Product Management permissions.
- Human Resources permissions.
- Sales Management permissions.
- Reports permissions.
- Individual permission checkboxes.
- All and None controls.
- Save Rights and Cancel buttons.

The Rights Dialog follows the 36 individual permissions defined in the project guide.

## Role-Based Access Design

The wireframes represent the three system roles:

- **Superadmin:** Full system access, including role assignment and System Settings.
- **Admin:** Manages business modules and regular User accounts but cannot view or modify Superadmin accounts.
- **User:** Accesses only the modules and actions granted by an administrator.

## Design System Consistency

All screens follow the HOPE, Inc. ERP Design System established in S1-UIX-01.

The designs maintain consistent:
- Inter typography.
- Color palette.
- Sidebar and navigation styles.
- Button and input styles.
- Tables and dialog components.
- Spacing and alignment.
