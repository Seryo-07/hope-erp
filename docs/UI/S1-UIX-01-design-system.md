# S1-UIX-01: Design System

## Task
Design system: colors, typography, and core components.

## Design Overview

Created the visual design system for the HOPE, Inc. ERP System to establish consistent styling across the application's interfaces.

## Design Deliverables

### 1. Typography
- Inter font family
- Typography scale
- Heading and body text styles

### 2. Color Palette
- Background colors
- Header colors
- Sidebar colors
- Button colors
- Profile colors
- Container and box colors

### 3. Core Components
- Sign In button
- Sign In form
- Register button
- Profile elements
