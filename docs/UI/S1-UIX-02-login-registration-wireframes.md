# S1-UIX-02: Authentication Wireframes

## Task

**Task ID:** S1-UIX-02

**Task:** Wireframes: Login, Register, Set/Reset Password.

## Design Overview

Created the authentication wireframes for the HOPE, Inc. ERP System to establish the layout, structure, and navigation flow of the authentication pages.

The wireframes illustrate how users interact with the system during registration, login, email verification, and password recovery.

## Design Deliverables

### 1. Landing Page
- Introduction to the HOPE, Inc. ERP System.
- Register button.
- Sign In button.

### 2. Login Page
- Email input field.
- Password input field.
- Show/hide password option.
- Sign In button.
- Forgot Password link.
- Registration link.

### 3. Registration Page
- Account registration form.
- Required user information.
- Password fields.
- Create Account button.
- Login link.

### 4. Email Verification Page
- Confirmation email message.
- Instructions for verifying the registered email address.

### 5. Verification Success Page
- Account verification success message.
- Continue to Login button.

### 6. Forgot Password Page
- Instructions for requesting a password reset.
- Email input field.
- Send Reset Link button.
- Back to Login link.

### 7. Reset Password Page
- New Password input field.
- Confirm Password input field.
- Show/hide password option.
- Reset Password button.

## Authentication Flow

The wireframes illustrate the navigation flow between the authentication pages:

- Landing Page to Login or Register.
- Registration to Email Verification.
- Email Verification to Verification Success.
- Login to Forgot Password.
- Forgot Password to Reset Password.
- Reset Password back to Login.
